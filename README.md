# writing-for-agents

Write or revise skills and AGENTS.md/CLAUDE.md instructions with clear triggers, executable steps and scoped reference loading.

This is an agent skill: `SKILL.md` tells an AI coding agent such as Claude Code when to use it and which steps to follow.

## Install

```bash
git clone https://github.com/alinvarat/skill-writing-for-agents.git ~/.claude/skills/writing-for-agents
```

Part of the [agent-skills](https://github.com/alinvarat/agent-skills) collection.
